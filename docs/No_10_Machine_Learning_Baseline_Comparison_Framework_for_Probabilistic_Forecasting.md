# No.10 - Machine Learning Baseline Comparison Framework for Probabilistic Forecasting.py

This script provides a robust framework for benchmarking several classical and tree-based machine learning models on a probabilistic time series forecasting task. Its primary purpose is to establish a strong performance baseline against which more complex models, such as the Spline Quantile Function Multi Transformer (SQF-MT), can be compared.
The framework automates the process of training, predicting, and evaluating seven different models. For each model, it generates not only point forecasts but also probabilistic forecasts (quantiles), which are then rigorously evaluated using a comprehensive suite of metrics covering accuracy, calibration, and distributional similarity.

Models Implemented
The framework includes a diverse set of models to provide a well-rounded comparison. Models that do not natively support quantile prediction are adapted to produce probabilistic forecasts by assuming a normal distribution of errors around their mean prediction.
Quantile Regression (QuantileReg): A linear model that directly estimates specific quantiles of the target variable.
Random Forest Quantile (RandomForestQ): An ensemble method that generates a predictive distribution from the outputs of all individual decision trees in the forest, allowing for non-parametric quantile estimation.
LightGBM Quantile (LightGBMQ): A highly efficient gradient boosting model that is configured to directly optimize the quantile loss function.
CatBoost Quantile (CatBoostQ): Another powerful gradient boosting model that supports quantile regression with its dedicated loss function.
Scikit-learn Gradient Boosting (GBoost(skl)Q): The classic gradient boosting implementation from scikit-learn, also configured for quantile regression.
AdaBoost (AdaBoostQ): A boosting ensemble where the probabilistic forecast is generated by adding normally distributed noise (based on training residuals) to the mean prediction.
Support Vector Regression (SVR): A kernel-based model for regression. Like AdaBoost, its probabilistic forecasts are derived from the mean prediction and the standard deviation of training errors.

Comprehensive Evaluation Framework
The script's core strength lies in its extensive evaluation module (calculate_metrics), which computes a wide array of metrics to assess different aspects of forecast quality.

Point Forecast Accuracy:
RMSE / MAE: Root Mean Squared Error and Mean Absolute Error.
R²: Coefficient of Determination.
Metrics are calculated for both the scaled data and the original, unscaled data.

Probabilistic Forecast Quality:
CRPS (Continuous Ranked Probability Score): A proper scoring rule that measures the overall quality of a distributional forecast, generalizing the MAE.
MSIS (Mean Scaled Interval Score): Evaluates the quality of prediction intervals by considering both their width and their coverage of the true values, scaled by the naive error of the dataset.

Calibration Assessment:
PIT (Probability Integral Transform): The mean and standard deviation of PIT values are calculated to assess if the forecasts are statistically well-calibrated. A perfectly calibrated model should have a PIT mean of 0.5 and a standard deviation of ~0.288.
Calibration Plots: Visual plots comparing the predicted quantiles to the observed frequencies, with a diagonal line representing perfect calibration.

Distributional Similarity:
Kullback-Leibler (KL) Divergence: Measures the difference between the probability distribution of the model's mean predictions and the distribution of the true values.
Wasserstein Distance: Also known as the Earth Mover's Distance, it measures the distance between the two distributions.
Quantile Loss:
QLM (Quantile Loss Mean): The average pinball loss across all evaluated quantiles (e.g., 0.1 to 0.9).
Individual Quantile Losses: The script also reports the loss for each specific quantile (e.g., ql10, ql50, ql90).

Workflow and Outputs
The script runs an end-to-end pipeline automatically:
Setup: A unique, timestamped directory is created to store all results for the specific run.
Data Loading: Training and testing data are loaded from the specified Excel files, along with a pre-trained scaler for inverse transformation.
Model Iteration: The script loops through each of the seven models. For each model, it:
Trains the model on the training data.
Generates mean, lower (10th percentile), upper (90th percentile), and a full set of quantile predictions on the test data.
Calculates the full suite of evaluation metrics.
Generates and saves model-specific plots.
Result Aggregation: After all models have run, the script aggregates the results into summary files and plots.

Generated Files
Upon completion, the following files will be available in the results directory:

Per-Model Outputs:
{ModelName}_predictions.png: A time-series plot comparing the model's median prediction and 80% prediction interval against the actual values.
{ModelName}_calibration.png: A plot assessing the calibration of the model's probabilistic forecasts.
Aggregated Outputs
metrics_comparison.csv: A summary table containing all calculated metrics for every model, allowing for easy comparison.
all_model_predictions.csv: A detailed CSV file containing the actual test values alongside the median, lower, upper, and all quantile predictions for every model.
model_performance_comparison.png: A final summary plot with bar charts comparing the performance of all models across key metrics, making it easy to identify the best-performing baseline models.
