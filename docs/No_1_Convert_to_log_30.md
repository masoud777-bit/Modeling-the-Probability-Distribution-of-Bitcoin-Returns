No.1 - Convert to log 30.py

A Python script for calculating and analyzing 30-day logarithmic returns of Bitcoin prices from historical data.

Overview
This project processes Bitcoin price data to:
Calculate 30-day logarithmic returns
Generate descriptive statistics (mean, standard deviation, skewness, kurtosis)
Create visualizations including histogram and time series plot
Export results to CSV format

Requirements
Python 3.
pandas
numpy
matplotlib

Usage
Place your Bitcoin price data in a CSV file named pricebitcoin.csv
Run the script: python bitcoin_analysis.py
Results will be saved in lreturns30.csv
Statistical summary and visualizations will be displayed

Output
CSV file with calculated log returns
Descriptive statistics in console output
Histogram of return distribution
Time series plot (2012-2024)

The analysis provides insights into Bitcoin's return characteristics and volatility patterns over time.
