Notebooks

This folder is dedicated to storing execution logs generated from running Jupyter notebooks or scripts.
Unlike the src/ directory, which contains the actual implementation code, this folder focuses only on the outputs and runtime logs for documentation and reproducibility purposes.

Purpose

Provide a record of model training and evaluation runs.
Capture experiment outputs (loss curves, metrics, warnings, runtime information).
Ensure transparency and reproducibility without duplicating code.

Notes

Source code is maintained exclusively in the src/ folder.
Only logs and execution artifacts are stored here, not the full notebooks or scripts.
Each log file corresponds to a specific experiment or module in the project.
